# 视频与博主：去哪看动作、听讲解

文字讲原理，视频看动作。这一页收集我们认为靠谱的视频博主和 UP 主。

> 我们只放名字和链接，不搬运视频。B 站上有不少国外博主的搬运，请优先看官方或已授权的账号。
> 这是编辑推荐，**不是证据等级**。视频里的观点，也请对照指南条目和原始研究来看。

## 我们怎么选人

满足下面至少 4 条才会收录：

1. **讲出处**：重要结论会引用研究，或者本人有运动科学、医学、康复相关的专业背景；
2. **敢说"不确定"**：不把单个研究说成定论，不卖焦虑；
3. **动作教学清楚**：看完能照着做，能讲清楚常见错误；
4. **利益透明**：带货、合作会标注；
5. **不推极端做法**：不推广极端节食、脱水、药物。
