# 7 天薄肌打卡

北清薄肌俱乐部第一期。目标不是 7 天练出薄肌，而是用 7 天把**训练、蛋白质、睡眠**三件事的节奏跑通。

## 打卡格式

在群里发：`【D3｜昵称｜✅/❌｜一句话】`

例：`【D3｜卧推五十公斤的博三｜✅｜午饭加了俩蛋，今天 92 g 蛋白】`

## 每日任务

| 天 | 任务 | 对应条目 |
|---|---|---|
| D1 | **测基线**：晨起体重、腰围（肚脐高度）、最多能做几个标准俯卧撑、平板支撑最长多久。在群里交"入会报告"：目标 / 每周能练几次 / 有没有器械 / 最大卡点 | [0.1](../guide/00-什么是薄肌/) |
| D2 | **全身 A**（见下表） | [1.3](../guide/01-训练/)、[1.4](../guide/01-训练/) |
| D3 | **食堂蛋白质日**：每餐拍照，估算全天蛋白质，目标约 1.6 g/kg 体重 | [2.1](../guide/02-饮食/)、[2.3](../guide/02-饮食/) |
| D4 | **全身 B**（见下表） | [1.3](../guide/01-训练/) |
| D5 | **睡眠日**：今晚睡够 7 小时，第二天打卡报入睡和起床时间 | [3.1](../guide/03-睡眠与恢复/)、[3.2](../guide/03-睡眠与恢复/) |
| D6 | **全身 A 升级**：每个动作比 D2 多做 1 次，或者换一个更难的变式 | [1.1](../guide/01-训练/) |
| D7 | **复测 + 复盘**：重测 D1 的项目，回答：哪天最难坚持？最大的卡点是什么？ | — |

## 训练内容

每组做到"还能再做 1–3 次"就停；组间休息 1–2 分钟。

| | 宿舍零器械版 | 健身房版 |
|---|---|---|
| **全身 A** | 俯卧撑 3 组 · 保加利亚分腿蹲 每侧 3 组 · 书包划船 3 组 · 臀桥 3 组 | 深蹲 3×8–10 · 卧推 3×8–10 · 坐姿划船 3×10–12 · 平板支撑 3×30–60 秒 |
| **全身 B** | 上斜或下斜俯卧撑 3 组 · 单腿罗马尼亚硬拉（可背书包）每侧 3 组 · 书包单臂划船 每侧 3 组 · 平板支撑 3 组 | 罗马尼亚硬拉 3×8–10 · 站姿推举 3×8–10 · 高位下拉 3×10–12 · 弓步蹲 每侧 2×10 |

书包装书负重时，先确认背带结实，动作全程慢速可控。

## 安全提醒

- 任何动作引起关节刺痛，立刻停下，换一个不痛的动作。
- 胸痛、头晕、心慌，马上停止运动并就医。
- D3 和 D5 不需要节食，也不要为了打卡好看少吃。

## 用什么记录

纸笔、备忘录、任何 App 都行。
