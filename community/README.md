# 一起练：饭搭子、练搭子、打卡搭子

一个人知道怎么做，和一个人能坚持做，是两回事。有个搭子，最难的"开始"和"坚持"会容易很多（实践经验）。

> 【利益相关】本页提到的食探、教链、健文社区都是发起人团队的产品。每一种搭子都可以只在俱乐部群里约，不用任何产品。

## 饭搭子：一起吃对

**为什么**：一个人吃食堂，最容易随手打两个素菜加米饭；两个人一起，会互相提醒"蛋白呢"。

**在群里约**，用这个格式：

```
【约饭｜北大家园｜周三 12:00｜目标：高蛋白｜还差 2 人】
【约饭｜清华紫荆园｜周五 18:00｜减脂期｜还差 1 人】
【约饭｜公司楼下轻食｜工作日午饭｜长期｜随时加入】
```

**用食探约**：食探有"约饭"功能，可以发起约饭、生成约饭邀请单、进入约饭房间；吃的时候各自拍照记录，就知道这顿蛋白够不够（[配套工具](../plans/)）。

**约饭时可以聊**：这顿蛋白够不够（[2.3](../guide/02-饮食/)）、谁的食堂哪个窗口最高蛋白，顺手发 issue，补全"北清食堂高蛋白地图"。

## 练搭子：一起练对

**为什么**：大重量卧推和深蹲需要有人保护；有人等你，就不容易翘课。

**在群里约**：

```
【约练｜北大邱德拔｜周四 19:00｜练腿｜深蹲 80kg × 5｜还差 1 人】
【约练｜清华综体｜周二周四 7:00｜上下肢 4 练｜找长期搭子】
【约练｜宿舍楼下单杠｜每天晚饭后｜引体从 0 到 1｜欢迎新手】
```

建议写清楚**地点、时间、练什么、大概水平**，搭子水平接近，练起来更舒服。

**用健文社区找**：在名片墙上填好三大项成绩，以及"我能提供"和"正在寻找"，比如：

- 我能提供：深蹲动作指导、引体从 0 到 1 的经验
- 正在寻找：周二周四早上一起练的卧推保护搭子

**用教链互相看进度**：加好友后能看到对方的训练动态和 PR 分享卡片。

## 打卡搭子：一起坚持

- **俱乐部打卡**：参加 [7 天薄肌打卡](../challenge/)，每天在群里发一句。
- **两人小组**：找一个搭子互相监督，一个人没打卡，另一个人就去问。
- **用产品打卡**：食探有签到打卡和排行榜；教链可以生成训练分享卡片。

## 约练安全与礼仪

1. **大重量要保护**：卧推和深蹲接近极限重量时，一定要有人保护，或者在深蹲架里设好安全杠。卧推时，保护者站在练习者头部后方，双手放在杠下方随时准备接；深蹲时，保护者站在练习者身后，跟着一起下蹲。
2. **第一次见面选公共场所**：校内场馆、商业健身房、食堂。
3. **不私下推销**：群里禁止私加群友推销课程和产品，包括发起人团队自己。
4. **不评价别人的身材**：每个人的起点不一样。
5. **尊重隐私**：不把群友的照片、成绩、身体数据转发到群外。

## 线下活动

俱乐部会不定期组织线下活动，比如引体教学、深蹲动作纠正、食堂高蛋白探店，时间和地点以群公告为准。
