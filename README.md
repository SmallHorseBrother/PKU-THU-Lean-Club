# How To 薄肌 Better

> **北清薄肌俱乐部 · 开源薄肌指南**
> AI 能替你写论文，替不了你练腿。

名字是梗，内容是正经的。

这是一份由北大、清华同学共建的开源指南，讲普通人怎么在**熬夜、久坐、吃食堂或外卖、住宿舍、没时间**这些约束下，把身体练得结实、精神。

## 薄肌三大理论

本指南的全部学问，浓缩成三大理论（名字是我们起的，研究是别人做的）：

| 理论 | 一句话 | 去哪看 |
|---|---|---|
| 🏋️ **大运动理论** | 肌肉只听得懂一句话："快举不动了" | [第 1 章](guide/01-训练/) |
| 🍚 **大食物理论** | 蛋白质是砖，热量是水泥，食堂是工地 | [第 2 章](guide/02-饮食/) |
| 😴 **大恢复理论** | 训练是给肌肉发消息，睡觉是肌肉回消息。你熬夜，肌肉就已读不回 | [第 3 章](guide/03-睡眠与恢复/) |

三大理论按阶段组装成一张[薄肌路线图](roadmap/)：入学体检 → 新手村 → 出村打怪 → 刷副本。每一关都告诉你练什么、吃什么、怎么恢复、什么时候升级。

另外，本指南坚持几件事：

- **证据诚实**：每条建议写明证据等级、成本和适用人群，引用的论文全部逐条核对过。我们零篇顶刊，引用的都是别人的顶刊。
- **讲原理**：附[运动生理学](knowledge/运动生理学/)、[解剖学](knowledge/解剖学与动作/)、[书单](knowledge/书单/)，每个数字都知道从哪来。
- **通用版 + 北清版**：场景类条目同时给通用做法和北大、清华的具体做法（精确到食堂名）。
- **能丢给 AI**：直接当你的私人教练，它不会收你课时费。

## 证据等级

| 等级 | 含义 |
|---|---|
| **A** | 顶刊盖章：有系统综述 / meta 分析，或权威机构指南支持 |
| **B** | 有实验撑腰：有随机对照试验或较一致的研究，但样本、人群或场景有限 |
| **C** | 老司机经验：专家经验、机制推理或实践共识，缺少高质量研究 |

每条还标注**成本**：时间、金钱、难度，各分低 / 中 / 高。

## 利益相关

发起人团队开发并运营以下产品，详细用法见[配套工具](plans/)：

| 产品 | 管什么 |
|---|---|
| **食探**（微信小程序） | 管吃：拍照记饮食、估算营养、食堂菜品、约饭、体重睡眠记录 |
| **教链**（微信小程序） | 管练：现成训练计划、按 1RM 自动算重量、逐组记录、找教练 |
| **健文社区** | 管圈子：名片墙记录三大项，找训练搭子 |

我们给自己定的规则：

1. 产品只出现在条目的「可用工具」和[配套工具](plans/)页，并标注【利益相关】。
2. 产品和其他工具用同一套标准评级。目前这些产品**都没有经过独立研究验证**，统一评为 **C**。
3. 指南的结论只跟着证据走。如果某条证据和产品的做法冲突，我们改产品，不改指南。
4. 不写任何功效承诺，不说"保证""一定"。
5. 每一条都会给出不用我们产品也能执行的做法。

发现哪条违反了上面的规则，欢迎直接提 issue。
