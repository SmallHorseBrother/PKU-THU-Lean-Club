# How To 薄肌 Better

> **北清薄肌俱乐部 · 开源薄肌指南**
> AI 能替你写论文，替不了你练腿。

名字是梗，内容是正经的。

这是一份由北大、清华同学共建的开源指南，讲普通人怎么在**熬夜、久坐、吃食堂或外卖、住宿舍、没时间**这些约束下，把身体练得结实、精神。

- 每条建议都写明**证据等级、成本和适用人群**；
- 场景类条目同时给**通用版**和**北清版**：北清版写到具体的食堂、体测和作息，通用版适合所有学生和上班族；
- 可以直接丢给 AI，当你的私人教练用。

## 三种用法

1. **直接读**：从下面的[目录](#目录)开始。新手建议按 0 → 1.5 → 2.1 → 2.3 → 3.1 的顺序看。
2. **丢给 AI**：
   - Claude / Claude Code：整个仓库就是一个 skill（见 [SKILL.md](SKILL.md)）。
   - ChatGPT / Kimi / 豆包 / DeepSeek：复制[通用提示词](prompts/)发给它，再问"我该怎么练"。
3. **一起练**：加入北清薄肌俱乐部，参加 [7 天薄肌打卡](challenge/)。

## 证据等级

| 等级 | 含义 |
|---|---|
| **A** | 有系统综述 / meta 分析，或权威机构指南支持 |
| **B** | 有随机对照试验或较一致的研究，但样本、人群或场景有限 |
| **C** | 专家经验、机制推理或实践共识，缺少高质量研究 |

每条还标注**成本**：时间、金钱、难度，各分低 / 中 / 高。

## 利益相关

发起人团队开发并运营以下产品，详细用法见[配套工具](plans/)：

| 产品 | 管什么 |
|---|---|
| **食探**（微信小程序） | 管吃：拍照记饮食、估算营养、食堂菜品、约饭、体重睡眠记录 |
| **教链**（微信小程序） | 管练：现成训练计划、按 1RM 自动算重量、逐组记录、找教练 |
| **健文社区** | 管圈子：名片墙记录三大项，找训练搭子 |

我们给自己定的规则：

1. 产品只出现在条目的「可用工具」和[配套工具](plans/)页，并标注【利益相关】。
2. 产品和其他工具用同一套标准评级。目前这些产品**都没有经过独立研究验证**，统一评为 **C**。
3. 指南的结论只跟着证据走。如果某条证据和产品的做法冲突，我们改产品，不改指南。
4. 不写任何功效承诺，不说"保证""一定"。
5. 每一条都会给出不用我们产品也能执行的做法。

发现哪条违反了上面的规则，欢迎直接提 issue。
