# How To 薄肌 Better

> **北清薄肌俱乐部 · 开源薄肌指南**
> AI 能替你写论文，替不了你练腿。

名字是梗，内容是正经的。

这是一份由北大、清华同学共建的开源指南，讲普通学生怎么在**熬夜、久坐、吃食堂、住宿舍**这些约束下，把身体练得结实、精神。每条建议都写明**证据等级、成本和适用人群**，也可以直接丢给 AI，当你的私人教练用。

## 三种用法

1. **直接读**：从下面的[目录](#目录)开始。
2. **丢给 AI**：
   - Claude / Claude Code：整个仓库就是一个 skill（见 [SKILL.md](SKILL.md)）。
   - ChatGPT / Kimi / 豆包 / DeepSeek：复制 [通用提示词](prompts/) 发给它，再问"我该怎么练"。
3. **一起练**：加入北清薄肌俱乐部，参加 [7 天薄肌打卡](challenge/)。

## 证据等级

| 等级 | 含义 |
|---|---|
| **A** | 有系统综述 / meta 分析，或权威机构指南支持 |
| **B** | 有随机对照试验或较一致的研究，但样本、人群或场景有限 |
| **C** | 专家经验、机制推理或实践共识，缺少高质量研究 |

每条还标注**成本**：时间、金钱、难度，各分低 / 中 / 高。

## 利益相关

发起人团队开发并运营以下产品：

| 产品 | 是什么 |
|---|---|
| **食探**（FoodLink） | 微信小程序。拍照或打字记录饮食并估算营养，内置校园食堂菜品库（覆盖范围在持续补充）。 |
| **教链**（CoachLink） | 线上执教平台。教练给学员下发训练计划，按 1RM 和百分比自动计算每组重量。 |
| **健文社区** | 健身与学习社区。用名片墙记录三大项成绩和技能供需，方便找训练搭子。 |

我们给自己定的规则：

1. 产品只出现在条目的「可用工具」部分，并标注【利益相关】。
2. 产品和其他工具用同一套标准评级。目前这些产品**都没有经过独立研究验证**，统一评为 **C**。
3. 指南的结论只跟着证据走。如果某条证据和产品的做法冲突，我们改产品，不改指南。
4. 不写任何功效承诺，不说"保证""一定"。
5. 每一条都会给出不用我们产品也能执行的做法。

发现哪条违反了上面的规则，欢迎直接提 issue。
