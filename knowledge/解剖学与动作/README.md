# 解剖学与动作：按"动作模式"认识肌肉

不用背每块肌肉的起止点。按动作模式来理解：一个计划只要覆盖下面这几类动作，全身主要肌群就都练到了。

## 六大动作模式

| 动作模式 | 健身房动作 | 宿舍 / 零器械动作 | 主要肌群 |
|---|---|---|---|
| **蹲** | 深蹲、腿举、高脚杯深蹲 | 自重深蹲、保加利亚分腿蹲 | 股四头肌、臀大肌、大腿内收肌 |
| **髋铰链** | 硬拉、罗马尼亚硬拉、臀桥 | 单腿罗马尼亚硬拉（背书包）、臀桥 | 臀大肌、腘绳肌、竖脊肌 |
| **水平推** | 卧推、哑铃卧推、双杠臂屈伸 | 俯卧撑（上斜 / 标准 / 下斜） | 胸大肌、三角肌前束、肱三头肌 |
| **垂直推** | 站姿推举、哑铃推举 | 屈体俯卧撑（臀部抬高） | 三角肌、肱三头肌、上斜方肌 |
| **水平拉** | 杠铃划船、坐姿划船、单臂哑铃划船 | 书包划船、弹力带划船 | 背阔肌、斜方肌中下部、菱形肌、三角肌后束、肱二头肌 |
| **垂直拉** | 引体向上、高位下拉 | 单杠引体、弹力带辅助引体 | 背阔肌、大圆肌、肱二头肌、肱桡肌 |

另外再加两类：

- **核心**：平板支撑、卷腹、悬垂举腿、抗旋转动作。主要练腹直肌、腹内外斜肌和腹横肌。
- **单侧动作**：弓步、分腿蹲、单臂划船。帮助发现和改善左右不平衡。

## 薄肌的"视觉关键肌群"

| 想要的效果 | 主要靠哪块肌肉 | 怎么练 |
|---|---|---|
| 肩宽 | 三角肌中束 | 侧平举、推举 |
| 倒三角（V 形背） | 背阔肌 | 引体（[第 6 章](../../guide/06-引体向上/)）、下拉、划船 |
| 挺拔、不圆肩 | 斜方肌中下部、菱形肌、三角肌后束 | 划船、面拉、俯身 Y 字举（[4.2](../../guide/04-久坐与体态/)） |
| 胸型 | 胸大肌（尤其上部） | 卧推、上斜卧推 |
| 手臂线条 | 肱二头肌、肱三头肌、肱肌 | 推和拉的复合动作，再加弯举和臂屈伸 |
| 腹肌线条 | 腹直肌（主要看体脂） | 先把体脂降下来（[2.2](../../guide/02-饮食/)），再加核心训练 |
| 臀腿 | 臀大肌、股四头肌、腘绳肌 | 蹲、髋铰链 |

## 每周组数怎么算

复合动作会同时练到好几块肌肉。2026 年一项分析训练量和效果关系的研究发现，把"主要发力肌群"算 1 组、"辅助肌群"算 0.5 组，预测训练效果最准（Pelland et al., 2026）。

**例子**：卧推 4 组 = 胸 4 组 + 肱三头肌 2 组 + 三角肌前束 2 组。

所以如果你每周已经做了 12 组卧推和推举，肱三头肌其实已经有 6 组左右了，不需要再加很多臂屈伸。

## 关节常识

- **肩关节**活动范围最大，也最需要稳定。推和拉的训练量要大致平衡，比如每周卧推和推举做 12 组，划船和引体也做 12 组左右。
- **膝盖可以超过脚尖。** 深蹲时只要脚跟不离地、膝盖和脚尖方向一致，膝盖超过脚尖是正常的动作轨迹（实践共识）。
- **腰背**：硬拉和划船时保持脊柱中立。重量大到腰背弯曲，就是该减重量了。
- **疼痛的分辨**见 [3.7](../../guide/03-睡眠与恢复/)。
