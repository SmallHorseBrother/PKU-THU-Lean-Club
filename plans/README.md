# 配套工具：食探管吃，教链管练，薄肌检测器管看

> 【利益相关】本页介绍的都是发起人团队开发的产品。它们没有经过独立研究验证，证据等级统一为 **C**。指南里每一条都能脱离这些工具执行，用不用全凭自愿。

指南告诉你**该怎么做**，工具帮你**每天做到**。下面按"你遇到的问题"来对照。

## 食探：管吃

每日热量和三大营养素怎么算、什么时候会建议你调整，见[产品算法](../knowledge/产品算法/)。

|---|---|---|
| 不知道这顿有多少蛋白质、多少热量 | **拍照记录 / 文字记录**：AI 估算热量和三大营养素；想更准用**精准分析** | [2.1](../guide/02-饮食/)、[2.5](../guide/02-饮食/) |
| 这顿吃得对不对 | **整餐点评**：告诉你这顿缺什么、多了什么 | [2.3](../guide/02-饮食/)、[2.7](../guide/02-饮食/) |
| 吃食堂不知道选什么 | **美食图谱 → 食堂**：按学校、校区、食堂、窗口浏览菜品；也可以上传你食堂的菜，帮同学补全 | [2.3](../guide/02-饮食/) |
| 减脂、增肌速度对不对 | **记体重 / 体重趋势 / 身体趋势**：看周平均和曲线 | [2.2](../guide/02-饮食/)、[2.6](../guide/02-饮食/) |

| 肌酸、蛋白粉吃了没 | **补剂柜** | [2.4](../guide/02-饮食/) |
| 一周下来整体怎么样 | **上周回顾 / 健康指数**（连续记录 2 天以上才会显示） | — |
| 想找人一起吃 | **约饭**：发起约饭、喊朋友一起吃，俱乐部群友可以直接约 | — |

**不用食探怎么做**：按 [2.3](../guide/02-饮食/) 的手掌法估算，用手机备忘录记体重和睡眠。

## 薄肌检测器（boji-detector）：管看

开源工具，代码在 [SmallHorseBrother/boji-detector](https://github.com/SmallHorseBrother/boji-detector)（MIT 许可）。照片只在你自己的电脑上处理，不上传；生成的标注图默认给头部打马赛克。

它把[路线图](../roadmap/)第 0 步要求的正面照变成可以前后对比的数字，每个数字都会在标注图上画出是在哪里量的：

| 你想知道 | 它量什么 | 对应指南 |
|---|---|---|
| 肩是不是变宽了、腰是不是变细了 | **倒三角**：三角肌外缘宽 ÷ 最窄腰宽 | [路线图](../roadmap/)阶段 2 的"薄肌重点" |
| 左右是不是一样 | **对称**：轮廓左右镜像的重合度、肩线倾斜、左右上臂粗细比 | — |
| 手臂有没有长 | **手臂**：上臂宽 ÷ 上臂长 | — |
| 腹肌出来了几块、清不清楚 | **腹肌**：找到腹白线和每条横沟，逐块量它被沟围住了多少 | — |

**先说清楚它的局限**（证据等级 **C**，和食探、教链一样没有经过独立研究验证）：

- 分数曲线还没有用真人评分校准。请主要看原始数值和**自己前后的变化**，不要拿分数和别人比。
- 腹肌数值依赖阴影：同一个人，光越柔和数值越低。对比时用同一地点、同一光线、同一距离。
- 只支持正面站立、手臂自然下垂并离身体约一拳的姿势。被画面截断的部位会直接标"测不了"，不会硬给数字。
- 目前是电脑上的命令行工具（需要 Python），还没有接入小程序。

**不用它怎么做**：每 4 周在同一地点、同一光线拍正面、侧面、背面照，配合腰围（[路线图](../roadmap/)第 0 步）自己对比。
