# 0. 什么是薄肌

### 0.1 薄肌不是"瘦"，是"有肌肉的不胖"

- **一句话**：薄肌 = 体脂不高 + 有一定肌肉量 + 体态挺拔。它不是医学或运动科学术语，是一种审美说法。
- **证据等级**：—（概念说明）
- **说人话**：只饿不练，掉的是肌肉，会变成"瘦但松"；只练不控制饮食，会变成"壮但厚"。薄肌是练和吃一起管出来的，所以这份指南里训练、饮食、睡眠三块都有。
- **怎么做**：从 [1.5 新手别急着分化](../01-训练/#15-新手别急着分化前-3-个月练全身) 和 [2.1 蛋白质](../02-饮食/#21-薄肌是吃出来的蛋白质每天每公斤体重约-16-克) 开始。
- **边界（重要）**：
  - 不追求某个体脂数字。体脂秤误差很大，看镜子、腰围、力量的变化更靠谱。
  - 不靠极端节食、催吐、过量有氧或脱水来"出线条"。
  - 如果你对吃东西有强烈的愧疚或焦虑，或者体重已经偏低还想继续减，请先找学校心理咨询中心或医院，而不是这份指南。
